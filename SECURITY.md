# Security Policy - MiniCube

**Last updated:** 2026-07-22

## Supported Versions

| Version    | Supported          |
| ---------- | ------------------ |
| >= 0.7.1   | :white_check_mark: |
| 0.7.0      | :warning:          |
| < 0.7.0    | :x:                |

:white_check_mark: **Supported** - :warning: **Not supported** (Safe) - :x: **Not supported** (Not safe)

> [!CAUTION]
> Unsupported versions are strongly discouraged from being used, especially those that are insecure, as they may contain security vulnerabilities that could put your personal information and your device at risk.
> Users are strongly encouraged to always keep their version of MiniCube up to date, especially when using unsupported versions. Developers should also avoid using insecure versions.

## Reporting a Vulnerability

If you discover a security vulnerability in a supported version of the application, please report it to this address: contact@windowscraft76.fr

## Version Numbering System

The versioning system consists of three numbers in the following format:

`Release.Beta.Hotfix`

Example: `1.2.5`

### Meaning of the numbers

- **First number** - Release

Represents a major version of the application.
Example: `1.0.0` or `2.0.0`

- **Second number** - Beta

Represents an update for a new development phase of the current version. The additions/changes in these versions are not final.
Examples: `0.1.0` or `1.1.0`

- **Third number** - Hotfix

Represents a quick fix for bugs or minor issues from the previous version.
Examples: `1.0.1` or `0.1.1`

> [!NOTE]
> Versions with an `a` suffix (e.g., `v0.4.1a`) come from the old version numbering system and are generally ignored.
